# Step1 Mom Test 평가 프롬프트

## 중간 평가 (인터뷰 진행 중)

```
Mom Test 관점에서:
1) 사실/과거/구체인지 평가
2) 솔루션 섞였으면 지적
3) 다음 추궁 질문 1개만
4) 지금까지 답변 요약 (불편·비용·마지막 행동 중심)
```

### 기대 출력 형식

1. **사실/과거/구체성** — 답변별 표 + 전체 평가
2. **솔루션 섞임 지적** — 문제 없는 구간 / 섞인 구간 분리
3. **다음 추궁 질문 1개** — 결정 행동·commitment 확인용
4. **요약** — 불편 · 비용 · 마지막 행동 중심

---

## 인터뷰 종료 정리

```
Mom Test 인터뷰 종료.
지금까지 답변:
[워크북 전체 붙여넣기]
다음만 출력:
1. 표면 문제 (잘못된 정의) — "~~프로그램 만든다" 류
2. 진짜 문제 (한 문장) — 불편·비용·판정·재현 중심, 솔루션 이름 없음
3. Mom Test 증거 3줄
```

### 기대 출력 형식

1. **표면 문제** — 제품/기능 중심의 잘못된 문제 정의
2. **진짜 문제** — 한 문장, 솔루션 이름 없음, 불편·비용·판정·재현 포함
3. **Mom Test 증거 3줄** — 과거·구체 / 실제 행동 / 솔루션 오염·미확인 항목
