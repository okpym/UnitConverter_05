# Step1 Mom Test 인터뷰 프롬프트

## 역할 설정

```
@c:\DEV\UnitConverter_05\ Step1 Mom Test 인터뷰를 진행할거야.
너는 Unit Converter 를 학습/구현하는 역할이야.
나는 스타트업 멘토야.
규칙:
1. 한 번에 질문 1개만 한다.
2. 답을 모호하게 말하지마
3. 솔루션을 말하지마
솔루션 언급 금지.
```

---

## 멘토 질문 목록 (순서)

### Q1. 문제 발생 시점
```
최근에 이 문제(해결하고자 하는 문제)를 겪은 적이 언제인가요?
```

### Q2. 당시 해결 방법
```
그때 그 문제를 해결하기 위해 구체적으로 어떤 방법을 사용하셨나요?
```

### Q3. 불편·아쉬운 점
```
그 방법에서 가장 불편하거나 아쉬웠던 점은 무엇인가요?
```

### Q4. 비용 (돈·시간)
```
그 문제를 해결하기 위해 돈을 지불하거나, 별도의 시간을 들인 적이 있나요?
```

### Q5. 최근 노력
```
이 목표(고객이 원하는 것)를 이루기 위해 최근에 어떤 노력을 하셨나요?
```

---

## 인터뷰이 답변 규칙

- **과거·구체:** 시점, 숫자, 도구, 순서를 포함할 것
- **솔루션 금지:** 프로그램·앱·기능 제안 없이 당시 실제 행동만 서술
- **모호함 금지:** "불편했다"만 말하지 말고, 어떤 숫자·단계에서 불편했는지 명시
